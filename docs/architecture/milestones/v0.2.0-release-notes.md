## 一句話定位

M4 釋出後使用者人工 review 揭露三塊 surface 需要**根本性重設計**（不是拋光）：
ChapterEditor / CharacterCard / Settings。v0.2.0 完成這三塊 + 順手清掉 M3/M4 P0 遺留。

---

## 主要功能

### 1. ChapterEditor 重設計 — AI 寫作工作台（Spec 003 + 005 + 006）

- **章 frontmatter 加 3 欄**（`participants` / `outline` / `requirements`），章節 .md 變成可攜資料
- **本章角色挑選器**（portrait grid 多選）；只有勾的角色 + character_status.md 進 prompt
- **上下文預覽面板**（read-only 摺疊）：synopsis + 前章 + story_status + 各 character_status
- **寫作參數 inline 編輯**：model 下拉 / temperature / per-章 system prompt 覆寫
- **兩階段 generate**：點「生成」先建 prompt 給 user 看 → user 編 prompt → 真送 LLM
- **採用流程**走 spec 006（dirty draft 三選一 modal）

### 2. CharacterCard 重設計 — portrait grid + 手動為主（Spec 002）

- 主視圖改 **portrait grid**（每張卡顯示頭像 + 名稱 + 定位）
- 核心區固定在上 + **5 個 tabs** 編 frontmatter 結構化欄位
- body 分成「## 角色描述（手動）」+ 「## AI 統整敘述」**兩段**，**互不覆蓋**
- AI 統整改 opt-in：手動按「✨ AI 統整」才呼 LLM；若 AI 敘述既有內容，二次確認 dialog
- 「親密」tab 改名「**性愛場景表現**」+ 預設展開

### 3. Settings 強化（Spec 009）

- **listModels()** for 7 個 provider — Anthropic / OpenAI / Google / xAI / Ollama / LM Studio / RWKV
- **Model 下拉選單**（取代文字輸入），24h SQLite cache + 手動 refresh，apiKey/endpoint 變動自動失效
- **Per-routing-slot systemPromptOverride**（chapter-writer 可寫；structured-data Agent 強制忽略 + UI disable）
- **Per-routing-slot temperature** 覆寫（spec 005 「本章覆寫」可進一步覆蓋）
- API key 預設**顯示**（本機個人工具）；toggle 純切 input type，不再清 React state
- Provider 卡片預設展開（取代之前的全收合）
- Reset 走自訂二次確認 dialog（取代 `window.confirm`），ESC + click-outside 可取消

### 4. P0 patch（不卡 spec 平行進）

- **TD-1**: status 寫檔走 `POST /api/projects/:hash/status/write`（讓 status-editor 與其他 Agent 一致）
- **TD-2/3**: hash 統一為 16-char + path canonicalize；新增 migration 處理舊資料
- **TD-9**: FirstLaunchWarningDialog ESC + backdrop 鎖（lock modality）

### 5. M5 開發中發現的 bug 全修

- Settings routing 三個 key（characterCardConsolidator / characterImageExtractor / statusShortener）PUT 時 silently dropped（zod `.strip()` 預設）
- CharacterEditor 儲存無錯誤回饋（按下沒反應，使用者以為沒事）
- Manual placeholder 把空字串讀回成 `(尚未填寫角色描述)` 假內容
- better-sqlite3 NODE_MODULE_VERSION 108 vs 147 — postinstall 自動 rebuild
- SSE write 對 client disconnect race：`Invalid state: ReadableStream is already closed`

## Breaking changes

無。所有 settings.yaml 新欄位（`systemPromptOverride` / `temperature`）為 optional，舊檔自動補 null。
舊 character.md 走 migration 自動把 body 拆成兩段。舊章節缺新 frontmatter 欄位時 reader 回 undefined（不報錯）。

## Upgrade path

```bash
# 1. pull latest
git pull
# 2. 重裝依賴（postinstall 會自動 rebuild native addons）
pnpm install
# 3. 跑檢查
pnpm typecheck && pnpm test
# 4. 開發
pnpm -F @novel-writer/api dev   # terminal A
pnpm -F @novel-writer/web dev   # terminal B
```

settings.yaml 舊版本啟動後會自動補空欄位。舊章節 .md / 角色 .md 第一次 read 時走 migration（讀完寫回新格式）。
