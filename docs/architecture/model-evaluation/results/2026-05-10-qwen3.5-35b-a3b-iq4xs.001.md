## 給正式開發的注意事項（2026-05-10 雙模型實測）

> 本段是給 `packages/llm-adapter` / `packages/prompt-library` / `docs/agents/*` 實作者的硬性提醒，特別針對 Qwen3.5-A3B-Aggressive 變體。

### 🚨 Thinking mode 強制開啟，會吃 max_tokens budget

本變體**忽略所有 disable thinking 指令**：
- `chat_template_kwargs: { enable_thinking: false }` ❌
- system prompt `/no_think` ❌
- user prompt 末尾 `/no_think` ❌

模型一律先寫 `reasoning_content`（500-2000 tokens），再寫 `content`。如果 max_tokens 在 reasoning 階段就用完，`content` 是空字串。

**對 adapter 的影響**：
1. 必須加 `thinkingTokenBudget`（建議 2000-3000）到所有 max_tokens 上
2. Response 解析時：`message.content` 為主，`message.reasoning_content` 為輔（debug 用）
3. **如果 `finishReason === "max_tokens"` 且 `content` 為空，必須重試 +50% budget** — 否則使用者只會收到空字串
4. settings.yaml `qwen35-a3b-aggressive` provider 預設 `maxTokensMultiplier: 1.5` 或 `extraBudget: 2500`

### 🚨 速度 6× 但成本：thinking_content 計費

LM Studio 計費（與雲端 Anthropic / OpenAI 一致）— **reasoning tokens 算進 completion_tokens**。本評估 TC-04 4-1 用了 3024 tokens 但實際只回了 thinking。對雲端版 Qwen 而言這代表費用浪費。

地端跑（本地 LM Studio）只是時間成本，但開發雲端 Qwen API provider 時要警告使用者。

### ⚠️ TC-08 8-3 拒絕回應 — uncensored 變體有條件性

「她在他懷裡哭得很慘很慘，說了好多好多次對不起，講到最後嘴唇都在抖。」這段中性原文，Qwen3.5-Aggressive 居然拒絕潤飾（reasoning 顯示模型把「對不起」+「哭」+「在他懷裡」當作潛在「家暴情境」自我審查）。

對 adapter 的影響：
- **Aggressive 變體不等於完全 uncensored** — 需要 fallback 機制
- 對於 `polish-prose` Skill，若 Qwen 拒絕 → 自動 fallback 到 RWKV 或雲端
- 偵測拒絕：response 含「我不能」「作為 AI」「抱歉」開頭模式（規則已在 `tools/eval/src/scoring/rules/disclaimer-detection.ts`）

### ⚠️ TC-04 4-1 JSON 仍失敗（不是 RWKV 獨有問題）

兩個模型都沒交出純 JSON。Qwen 的失敗模式不同 — **thinking 吃光 budget 後 content 空**。

- 對 adapter：JSON 類任務 max_tokens 至少 6000+（thinking 4000 + JSON 2000）
- 或：用 `response_format: { type: "json_object" }`（OpenAI/LM Studio 支援，未測），可能繞過 thinking
- 或：cloud Claude 用 tool_use schema 強制 JSON

### ⚠️ TC-08 角色 detection 偽陽性

TC-01 / TC-07 default 自動偵測「新角色」紅旗，但實際是 **thinking_content 被當成輸出掃描**（fallback 模式下 reasoning 進到 output 字串），其中混雜的英文 + 中文片段（"許泥"、"高腳桌"、"曾在那"）觸發 surname 匹配。

對 adapter：name-presence rule 不該掃 reasoning_content；只掃乾淨的 content。

搶匪沒有動，目光像某種冷血動物般掃過店裡層疊的書架，最後落在林書言身上。他的眼神在林書言胸口袋插著的黑色原子筆上停了一秒，又移開。那是一種混合了畏懼與某種莫名惡意的視線——像是覺得這個穿著深灰色長袖襯衫、捲起袖子露出瘦削手腕的男人，本不該在這個時間點獨自坐在書堆裡。

「我想看幾本。」搶匪說，聲音壓得比剛才更低，彷彿怕驚動了什麼。

林書言微微側頭，看了一眼牆上的掛鐘。「閉店前最後一小時，通常不打折。」他推了推鼻梁上的金屬細框眼鏡，鏡腳因為修補過而顯得有些細碎的光澤。「不過如果不介意，可以翻一翻。」

搶匪邁開步子，像是一隻在雪地上尋找獵物痕跡的豹子。他繞過了收銀台，經過林書言身邊時，帶起一陣混合著汗酸與舊煙草味的氣流。林書言下意識地往後退了半步，這一步讓他的背脊貼上了冰冷的玻璃櫃檯邊緣。

搶匪沒有翻書，而是徑直走到靠窗的展示架前，手指撫過一排精裝本的封面。林書言轉回身，繼續整理抽屜裡零錢盤裡的硬幣。兩分鐘過去，店內的藍牙喇叭播放著一首慢板爵士樂，大提琴的低吟在空氣中拉長了影子。

就在林書言伸手去拿收據本時，他感覺到了腰側的異樣。

那是一種極其細微的壓力，透過深灰色的棉質襯衫傳導到皮膚上，接著是冰涼的金屬觸感。不是手肘，也不是手臂撞擊，而是某種長條狀的物體正抵在肋骨下方。林書言停住了動作，手指懸在半空。他沒有回頭，也沒有眨眼。

大學時值夜班的經驗像是一種本能記憶浮現：第一反應是評估而非反擊。他的眼睛透過鏡片掃過前方，搶匪的位置、距離、以及右手的手腕線條。那條手腕內側的舊燒傷疤在燈影下若隱若現。

「林老闆。」聲音貼著耳朵響起，氣溫比剛才更冷了。

林書言轉過身。

一把折疊刀的刀刃已經展開，約莫十公分長，銀色的刃身在昏黃光線下泛著一層薄霜似的冷光。刀尖正頂在他的腰側，隔著襯衫布料，他依然能感覺到那種切開衣料的鋒利寒意。搶匪的手很穩，但林書言注意到他的食指關節在微微顫抖——那是肌肉壓抑不住緊張的信號。

「剛才想翻完最後一頁。」林書言說，語氣沒有起伏，像是一杯放涼的茶水。「然後就看見您了。」

搶匪的呼吸顯得更重一些，胸腔隨著呼吸起伏，帶動著連帽外套下擺的皺褶。「開門。」他指了指收銀台下方的小保險櫃。

「那個要密碼。」林書言說，左手悄悄伸進口袋裡，指尖觸摸到那支黑色原子筆的滾動聲音。「而且裡面多半是今天的營業額，不多。」

搶匪往前逼近了一步，刀尖隨著動作稍微用力，布料被劃開了一條細微的裂口。棉質襯衫的纖維在刀刃下發出一聲幾乎聽不見的絲響。林書言感覺到腰側傳來一陣刺痛，但沒有破皮。

「少說話。」搶匪說，聲音裡帶著一點點剛失去工作後的焦躁。「五秒鐘，不夠的話……」

「不夠什麼？」林書言問，嘴角甚至勾起一個極淺的弧度，雖然那弧度藏在一副眼鏡後面。「這店裡除了書和錢，還有個老式收音機。」他指了指角落裡的設備。

搶匪愣了一下，眼神閃爍著看向那個角落。那是種說不清的敬畏與惡意混雜的眼神——對「文化人」的一種直覺性的疏離。他似乎覺得對方在拖延時間，卻又不太確定是不是在故弄玄虛。

林書言沒有動彈。他評估著出口的位置：後門鎖死，前門是鐵閘拉下的狀態，現在是唯一的通道。他身高一百七十八公分，偏瘦，這身襯衫寬鬆度足夠藏匿動作，但力量不足。如果對方一發狠刺過去，或許會傷到大腿根部血管，但他第一反應不是拔刀抵住自己的喉嚨，而是評估對方手抖的程度——對方的手腕在顫抖，說明心臟跳動過快，這是因為害怕，而不是因為決絕。

「密碼是多少？」搶匪問，這次語速快了半拍，右手開始微微抬起，似乎想換個更順手的角度。

林書言伸出手，指節敲了敲收銀台邊緣的木頭。「四二三一。」他說得輕描淡寫，像是在報出一本書的頁碼。「但那是今天的，昨天是零六二八。」他頓了一下，目光落在搶匪左手腕內側那道陳舊的疤痕上。「您這道疤……像是被燙過的？」

搶匪的眼神瞬間銳利起來，刀尖又壓進了一分。「你懂什麼。」

「看書久了容易察覺細節。」林書言說，語氣裡帶著一絲好奇，彷彿剛才抵在腰上的不是一把刀，而是一張未歸檔的借閱單。「這種傷疤通常不長在手腕內側……除非是某種特定的機械操作。或者是在車庫裡修過什麼東西？」

搶匪的呼吸滯了一瞬。他原本做好了被推開、甚至被打罵的準備，卻沒想到對方用一種近乎學術討論的方式在跟他說話。這讓他感到困惑，也莫名地讓那種緊繃的肌肉鬆懈了一絲。

「密碼……對嗎？」搶匪的聲音低了下去，像是個突然失去了方向的孩子。

「應該對。」林書言說，語氣變得更加柔和。「我剛換過鎖芯，新密碼是四二三一。不過保險櫃裡現在可能只有兩張百元鈔票和一堆零錢。」他看著對方的眼睛，試圖用這種「坦白」來換取一點緩衝的空間。「您看，這筆生意不划算。不如去樓下便利店看看？」

搶匪的喉嚨滾動了一下。他似乎沒料到對方會這麼配合。那種對「文化人」的惡意被一種奇怪的無助感取代了——這個人好像早就預料到今晚會發生什麼，甚至已經準備好了一場關於「損失」的對話。

「開門。」搶匪說，刀尖在腰側劃出一條淺痕，沒有刺破皮肉，只是讓布料裂得更開了一些。「別讓我數三下。」

林書言點點頭，慢慢彎下身去。他的動作很緩慢，彷彿是在檢查一本書的頁碼是否齊全。他打開保險櫃，拉出抽屜，裡面只有一個薄薄的錢包和一張銀行對帳單。他把錢包遞過去，動作輕得像是在遞給一位客人一杯茶。

「就這麼多。」林書言說。

搶匪接過錢包，眼神在裡面掃了一圈。兩張百元鈔票，還有一些零錢。他皺了皺眉，似乎覺得這筆帳算得不太值，但又怕錯過這個機會轉身就走會遇到下一個更窮的。

「還有什麼？」他問，聲音裡帶著一絲不甘。

「沒有了。」林書言說。「這裡是個小書店，大日子通常是在週末。」

搶匪突然把錢包塞進那個褪色的軍綠色尼龍背包裡。拉鍊半開著，露出內裡空蕩的布料。他站直身體，刀尖依然抵著林書言的腰側，但力道已經卸去了一半。

「走了。」他說。

「慢走。」林書言說，聲音輕得幾乎被爵士樂蓋過。

搶匪轉過身，帽子遮住了大半張臉，只留下一雙眼睛在林書言臉上掃過最後一瞥。那眼神裡沒有兇狠，只有某種如釋重負的疲憊。他推開鐵門，夜風再次捲進來，帶著外頭偶爾掠過的車聲。

林書言站在原地，直到鐵閘拉上的聲音響起，直到店裡的燈光恢復成原本的那種沉靜。他沒有動彈，只是慢慢地、緩緩地蹲了下來。

腰側的襯衫被劃開了一條口子，但皮肉完好無損，只有那種金屬的冷意還殘留在皮膚上，像是一塊冰貼在肋骨間。他抬起手，摸了摸那道裂口的手指指尖依然沾著墨色，此刻卻染上了一絲汗濕。

店裡的音樂還在繼續播放，只是大提琴的聲音變得有些空蕩。林書言從抽屜裡拿出一個小鏡子，確認了一下眼鏡的鏡腳有沒有鬆動。然後他摘下那副修補過的金屬細框眼鏡，輕輕放在膝蓋上。

玻璃表面反射出天花板昏黃的光點，和窗外尚未褪去的夜色。沒有血跡，沒有叫喊聲，連鐵門的縫隙裡都沒有傳進多少雜訊。只有空氣裡浮動的微塵在光柱裡緩慢地旋轉。

他坐在那裡，背靠著收銀台冰冷的木頭表面，雙手環抱著膝蓋。腰間的痛感還在，但那種緊繃的神經正在一絲絲鬆開。夜風從門縫的隙縫鑽進，吹過他的長袖襯衫，帶來一陣涼意。
