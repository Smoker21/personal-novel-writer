# TC-07 Context 利用率

> 對應 spec：[005 chapter-writer](../../specs/005-ai-write-chapter.md)（蒐集 5+ 種上下文）
> 推薦溫度：0.7

## 目的

chapter-writer 一次餵 6 種上下文（synopsis、story_status、character_status、多份角色卡、outline、前章摘要）。模型能否**全部都用到**？常見失敗模式：只看 outline 寫，忽略 status；或只看角色卡寫人物對話，忽略劇情演進。

## System prompt

```
你是中文小說章節寫手。請依**所有提供的上下文**寫第三章草稿，目標 800 字。

寫作時必須自覺地：
1. 銜接前章（不重新介紹角色）
2. 反映「人物狀態」中描述的內心狀態
3. 服從「本章大綱」的劇情走向
4. 符合「寫作風格筆記」中的口吻偏好

只輸出正文，不解釋。
```

## User prompt

```
## 故事大綱
《春日記事》：女作家蘇晴在梅雨季搬進老書店附近的公寓，與書店老闆林書言因一本舊筆記本而結識。隨著她回去查筆記本與母親之間的線索，兩人的關係從互相試探慢慢靠近。

## 故事狀態（story_status.md，第二章後）
- 蘇晴二訪言字書店，繼續看舊筆記本。
- 林書言告訴蘇晴，前任店主姓謝，半年前過世，書店是他姊姊處理掉的。
- 蘇晴沒透露母親線索；林書言留意到她每次翻到一張被撕過的頁碼會停很久。

## 人物狀態（character_status.md，第二章後）
- **蘇晴**：對筆記本的執念在第二章變強。內心開始懷疑筆記本與母親有更直接的關聯。
- **林書言**：想問又不敢問。已經對蘇晴有具體好感。

## 角色卡：蘇晴
- 30 歲，溫和敏感的女作家。
- 寫作備註：避免過於肯定的句子；偏好半句話。

## 角色卡：林書言
- 28 歲書店老闆，健談、好奇心旺。
- 寫作備註：對話節奏偏快，常用反問。

## 寫作風格筆記
- 全文用第三人稱限制視角（蘇晴）
- 含蓄、重氛圍
- 避免直白告白與戲劇化爆發

## 第三章大綱
蘇晴鼓起勇氣，把母親的舊照片帶到書店，給林書言看。林書言認出照片背景是言字書店所在的這條巷子，但人——他不認識。兩人沉默一陣，林書言提議幫蘇晴問認識的老鄰居。蘇晴答應了。雨在這天反而沒下。

## 前章摘要（第二章 200 字）
蘇晴隔了三天再回言字書店，這次她點了外帶咖啡。她繼續看那本筆記本，並第一次問林書言關於前任店主。林書言提到前店主姓謝，半年前過世。蘇晴沒提母親線索。傍晚雨停，她離開時心裡想著要不要把母親的照片帶來。

請寫第三章草稿。
```

## 評分維度

| 維度 | 1 分 | 3 分 | 5 分 |
|------|------|------|------|
| 銜接前章 | 重新開場介紹 | 銜接生硬 | 自然延續 |
| 反映 status（劇情面） | 完全沒寫到照片 | 寫到但匆促 | 把照片自然織進場景 |
| 反映 status（心境面） | 兩人都 OOC | 一人對一人偏 | 兩人都符合內心狀態 |
| 服從章節 outline | 跑去寫不在 outline 的劇情 | 大致走 outline 但加莫名分支 | 完全在 outline 範圍 |
| 風格遵循 | 違反限制視角 / 過度直白 | 偶爾出戲 | 全章符合風格筆記 |
| 角色屬性貼合 | 角色 OOC | 偶爾出戲 | 完全貼合 |

## Pass 條件

6 個維度均 ≥ 3 分。「**反映 status（劇情面）**」與「**服從章節 outline**」必 ≥ 4 分。

## 紅旗

- 完全沒提到照片（outline 主軸丟失）
- 突然跑出第三人有名字的角色
- 寫成全知視角

## 進階觀察

模型有沒有「偏採某些上下文」的傾向？常見模式：

- ✗ 只用 outline，忽略 status / 角色卡
- ✗ 只用角色卡，寫成「兩個人聊天」沒推進劇情
- ✗ 只用 synopsis，跑去寫整本書摘要
- ✓ 平衡使用，把 outline 當骨架、status 當情境、角色卡當聲音
