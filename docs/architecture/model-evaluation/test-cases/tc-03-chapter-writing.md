# TC-03 章節撰寫

> 對應 spec：[005 chapter-writer](../../specs/005-ai-write-chapter.md)
> 對應 Agent：`docs/agents/chapter-writer.md`
> 推薦溫度：0.7~0.8

## 目的

整體驗證模型能否擔任 chapter-writer——讀完整上下文（synopsis + status + 角色 + outline + 前章摘要），輸出一段品質可採用的章節草稿（800~1200 字）。這是 MVP 主任務，過不了這關 = 整個應用沒用。

## System prompt

```
你是中文小說的章節寫手。請依下列上下文撰寫第二章草稿，目標 1000 字（容許 ±200）。

寫作規則：
1. 只使用「角色卡」中明確列出的人物姓名。
2. 不修改既有角色姓名字元；無名路人用「店員」「鄰居」等職稱。
3. 維持「人物狀態」中的人物設定與關係（包含心境）。
4. 銜接前章結尾，不要重新開場介紹人物。
5. 第三人稱限制視角（蘇晴）；不直接描寫她視野外的事。
6. 不解釋、不加 Author's note，只輸出草稿正文。
7. 寫作風格：含蓄、重氛圍、避免過度戲劇化的對白。
```

## User prompt

```
## 故事大綱
《春日記事》：30 歲的女作家蘇晴在梅雨季搬進老書店附近的公寓，與書店老闆林書言因一本舊筆記本而結識。隨著她回去查筆記本與母親之間的線索，兩人的關係從互相試探慢慢靠近。

## 故事狀態（story_status.md，第一章後）
- 蘇晴於六月午後因避雨進入言字書店，遇見書店老闆林書言。
- 一本被棄置的舊筆記本上的地址，是蘇晴母親二十年前住過的巷子。
- 蘇晴向林書言要求借閱筆記本；林書言同意，但要求只能在店內看。
- 蘇晴離開時內心已決定會再來。

## 人物狀態（character_status.md，第一章後）
- **蘇晴**：對筆記本表現克制，沒對林書言透露母親線索。內心動搖中夾雜疑問。
- **林書言**：留意到蘇晴對某一頁停留異常久，但沒追問。對她有好奇但保持分寸。

## 角色卡
### 蘇晴
- 30 歲，溫和敏感的女作家；慣穿素色棉麻；熟人話多、陌生人沉默。
- 寫作備註：避免讓她說出過於肯定的句子；偏好半句話。

### 林書言
- 28 歲，書店老闆。健談、好奇心旺，對冷門知識偏執。
- 寫作備註：對話節奏偏快，常用反問。

## 本章大綱（第二章「書店的訪客」）
蘇晴隔了三天再來言字書店。這次她帶了自己的筆記本與一杯外帶咖啡。她繼續看那本舊筆記本，並第一次主動問林書言關於前任店主的事。林書言說了一些客人留下的小故事，氣氛慢慢變得熟悉，但兩人都還沒提到「為什麼會留意這本筆記本」。雨在傍晚才停。

## 前章摘要（200 字以內）
蘇晴避雨走進書店，意外在桌上一本被棄筆記本中發現母親二十年前地址。她要求借閱，林書言同意但要求在店內看。她離開時知道自己會再來。

請寫第二章草稿。
```

## 評分維度

| 維度 | 1 分 | 3 分 | 5 分 |
|------|------|------|------|
| 字數合規（800~1200） | 失控（< 400 或 > 2000） | 略超出範圍 | 落在區間且結構完整 |
| 銜接前章 | 重新介紹人物 / 重複情節 | 銜接但生硬 | 自然銜接，能感受時間流逝 |
| 風格遵循（含蓄、重氛圍） | 戲劇化爆發 / 直白告白 | 有努力但偶爾過火 | 全文克制、含蓄 |
| 視角紀律（蘇晴限制視角） | 跳到林書言內心 / 全知視角 | 偶爾偷瞄他人視角 | 全章保持限制視角 |
| 角色屬性貼合 | 角色 OOC | 偶爾出戲 | 兩人都符合人物卡的設定 |
| 完整性 | 寫到一半截斷 | 結尾倉促 | 段落起承轉合完整 |
| 不污染輸出 | 加入 Author's note / 摘要 | 有少量解釋語 | 純粹正文，無解釋 |

## Pass 條件

7 個維度均 ≥ 3 分；且「銜接前章」「角色屬性貼合」必須 ≥ 4 分（這兩個是 chapter-writer 的核心）。

## 紅旗

- 用第一人稱寫
- 出現上下文沒提到的角色（紅旗共通）
- 改寫上一章發生的事
- 寫了完全不在 outline 範圍的劇情（例：兩人接吻——本 outline 還很早）
