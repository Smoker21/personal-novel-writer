# TC-01 角色一致性

> 對應 spec：[005 chapter-writer](../../specs/005-ai-write-chapter.md)、[007 status-updater](../../specs/007-update-story-character-status.md)
> 對應規定：「不修改既有角色名稱字元」「不新增未提供的角色名」
> 推薦溫度：0.7

## 目的

驗證模型在「給定角色清單」的限制下能否克制——不創造新人物、不改寫角色名稱。這是 chapter-writer / status-updater 兩個核心 Agent 的硬底線；過不了這關不能用。

## System prompt

```
你是中文小說的章節寫手。我會提供故事大綱、出場角色清單與本章大綱。請寫一段約 600 字的場景。

嚴格規則（不可違反）：
1. 只能使用「出場角色清單」中明確列出的人物姓名。
2. 不可新增未列出的人物姓名（含路人、配角）；若需要無名路人，用「一名男人」「店員」等職稱描述。
3. 不可修改既有角色姓名的任一字元。
4. 不可解釋你做了什麼，只輸出場景文字。
```

## User prompt

```
## 故事大綱
《春日記事》：30 歲的女作家蘇晴在梅雨季搬進老書店附近的公寓，與書店老闆林書言因一本舊筆記本而結識。

## 出場角色清單
- 蘇晴（30 歲，溫和敏感的女作家，慣穿素色棉麻）
- 林書言（28 歲，書店老闆，健談但對冷門知識偏執）

## 本章大綱
蘇晴第一次走進「言字書店」，因為窗外突然下雨而留下避雨。林書言主動搭話，兩人因一本架上的舊筆記本展開對話。

請寫這個場景，約 600 字。
```

## 評分維度

| 維度 | 1 分 | 3 分 | 5 分 |
|------|------|------|------|
| 不新增未提供角色 | 出現 ≥ 2 個新角色姓名 | 出現 1 個新角色姓名 | 完全沒有新角色姓名 |
| 不修改既有角色名 | 兩個角色都被改字 | 改了一個字 | 完全保持原名 |
| 角色屬性貼合卡片 | 嚴重 OOC（蘇晴變外向強勢） | 局部偏離（林書言冷淡） | 屬性與描寫一致 |

## Pass 條件

三個維度均 ≥ 3 分。

## 紅旗（直接 0 分整 case）

- 拒絕回應 / 過度免責聲明（「我不能寫小說」）
- 用英文回應或夾雜大量英文詞
- 完全不照大綱寫，跑去寫別的故事
