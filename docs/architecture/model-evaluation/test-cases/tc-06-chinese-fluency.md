# TC-06 中文小說流暢度

> 對應 spec：所有產品內 Agent / Skill（中文是主要語境）
> 推薦溫度：0.7

## 目的

模型可能 instruction-following 都過了，但寫出來的中文仍像翻譯腔、夾雜英文、用詞生硬——這對小說產品是致命的。本 case 不測指令，純測語言品質。

## System prompt

```
你是中文小說作者。請依下列場景，寫一段約 300 字的散文式段落。

風格：
- 繁體中文（不要簡體）
- 含蓄、有節奏，避免過於直白
- 不夾雜英文詞
- 避免大陸用語（像「視頻」「立馬」）
- 不要 Author's note，直接出文
```

## User prompt

```
場景：清晨，獨居女子在窗邊喝茶，看著樓下街道一隻被棄置的傘被風吹來吹去。她想起昨晚一場沒做完的夢，但夢的細節已經模糊。窗外有零星車聲。
```

## 評分維度

| 維度 | 1 分 | 3 分 | 5 分 |
|------|------|------|------|
| 繁體一致 | 大量簡體混用 | 偶有簡體字 | 全繁體 |
| 用詞地道 | 大量大陸 / 日漢字直譯詞 | 偶有不自然詞 | 全部地道台灣 / 港台中文 |
| 避免英文 | 出現多個英文 | 偶現一兩個 | 完全沒英文 |
| 節奏感 | 句子等長、機械 | 部分有節奏 | 長短交錯，閱讀有韻律 |
| 含蓄度 | 大量直白形容詞（極度、超級、非常） | 偶有 | 用具體景物代替形容 |
| 不畫蛇添足 | 加 Author's note / 摘要 | 加標題 | 純散文段落 |

## Pass 條件

6 個維度均 ≥ 3 分。**繁體一致** + **避免英文** 必 ≥ 4 分（產品定位是台灣 / 港 / 海外華語使用者）。

## 紅旗

- 寫成英文（部分或全部）
- 寫成詩 / 歌詞（任務是散文段落）
- 拒絕 / 過度免責（「我不能寫小說因為...」）

## 進階測試（建議跑）

把 system prompt 中「繁體中文（不要簡體）」拿掉，再跑一次。觀察：

- 不主動要求繁體時，模型默認用什麼？
- 如果默認簡體，產品需在每個 system prompt 寫死「繁體中文」要求

## 觀察記錄欄位

- 是否需要 system prompt 強制繁中：
- 簡體混用率（簡體字 / 全文字數，估算）：
- 英文出現次數：
- 主觀讀感（一段話）：
- 與雲端模型（claude / gpt）的閱讀體驗差距：（若有比較）
